## Section 1: Hiện trạng & Compatibility Matrix

Hiện hệ thống khai báo 5 provider trong `AGENT_PROVIDERS = ["claude", "cursor", "codex", "antigravity", "copilot"]` (`src/agent/provider.ts:7`), với `"claude"` là mặc định fallback khi thiếu/rỗng/không hợp lệ (`src/agent/provider.ts:39-50`).
Ở tầng workflow, `TURN_ADAPTERS` (`src/agent/harness/turn.ts:57-112`) điều phối 5 adapter; ở tầng completion phụ trợ & chat, `runners` (`src/agent/complete.ts:242-252`) ánh xạ 5 `CompletionRunner`. Tuy nhiên, mức độ hỗ trợ, cơ chế bảo mật, telemetry và vòng đời giữa 5 provider hiện **lệch nhau đáng kể** và metadata năng lực đang bị phân tán ở 5 nơi khác nhau (`providerCapabilities.ts`, `complete.ts`, `providerStatus.ts`, `handoff.ts`, và từng thư mục adapter).

> Quy ước trạng thái trong bảng: **Full** (đầy đủ), **Partial** (chỉ hỗ trợ một phần hoặc còn lỗi thực thi), **Missing** (chưa hỗ trợ / không có adapter tương đương).

### 3.1. Mô hình `ProviderCapabilities` hợp nhất

```ts
export interface ProviderCapabilities {
  id: AgentProvider;

  // 1. Controls & Config surface
  controls: {
    model: boolean | null; // null = phụ thuộc CLI discovery (Cursor)
    maxTurns: boolean;
    efforts: readonly ("none" | "minimal" | "low" | "medium" | "high" | "xhigh" | "max")[];
    options: readonly ("sandbox" | "max_concurrent")[];
  };

  // 2. Execution guarantees (workflow enforcement)
  guarantees: {
    preToolPolicy: boolean; // PreToolUse hook thực sự chặn trước khi chạy
    hookBypassDetection: boolean; // Phát hiện nếu mọi native/MCP tool chạy không qua hook
    writeSandbox: boolean; // Sandbox ghi hiệu lực thực sự (không phải no-op!)
    networkIsolation: boolean; // Sandbox chặn mạng thực sự
    osIsolation: boolean; // Chạy được trong bwrap / isolation.ts
    delegation: boolean; // Subagent read-only có policy enforcement
    allowedToolsEnforcement: "native" | "hook_only" | "unsupported";
    microProfile: boolean; // Cho phép profile MICRO (đòi hỏi preToolPolicy + scope lock)
    externalSkills: boolean; // Tương thích external skills metadata
  };

  // 3. Runtime & Session semantics
  runtime: {
    sessionResume: boolean; // Workflow resumeId & chat keep/session_id
    postSubmitReaper: boolean; // Có khả năng ngắt background shell sau submit_result
    incompleteDetection: "strict_result" | "best_effort";
    bridgeRpcTimeoutMs: number; // Chuẩn hóa >= 30 * 60_000 (tránh bug 65s như Cursor)
  };

  // 4. Completion, Chat & Telemetry semantics
  completion: {
    visionImages: boolean; // Nhận ảnh base64 trong chat
    chatNativeTools: boolean; // SDK/MCP native tool loop trong completeForRun
    streamingPartials: boolean; // Token delta + reasoning stream
```
