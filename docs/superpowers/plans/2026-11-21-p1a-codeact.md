# P1-A CodeAct Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only `execute_code` capability: a short JavaScript program runs in the existing OS sandbox and calls authorized read-only registry tools through a trusted parent broker, returning a bounded result with evidence refs.

**Architecture:** `src/codeact/execute.ts` (parent) launches `src/codeact/runner.mjs` with `node --permission` inside `sandboxInvocation` (bwrap, no network, masked secrets, cgroup/rlimits); the runner speaks JSON lines on stdio; every nested call is resolved by the broker through `callTool(..., {mode:"analysis"})`. Workflow exposes it as the context tool `execute_code`, Chat as `code.execute`.

**Tech Stack:** Node 22 (`--permission`), bubblewrap via `src/agent/isolation.ts`, PostgreSQL migration, node:test.

**Spec:** `docs/superpowers/specs/2026-11-21-p1-codeact-lsp-taint-design.md` (section A).

## Global Constraints

- Disabled by default (`config.codeAct.enabled = false`); unavailable unless the isolation probe is available — never run user code in the worker process.
- Read-only only: nested tools must be registry tools with `readOnly: true`, executed with `mode: "analysis"`.
- No credentials, DB URL or platform env inside the sandbox (`isolatedEnvironment(null)`), no network (no egress spec).
- Defaults: timeoutMs 20000, maxCodeBytes 16384, maxOutputBytes 16000, maxCalls 20, maxResultBytes 2000000, maxConcurrency 4, callTimeoutMs 15000, memoryMb 256.
- Error categories: `unsupported | unauthorized | invalid_input | budget_exceeded | timeout | canceled | dependency_unavailable | internal`.

## Review Focus

- A program that never returns / spins (`while(true){}`) → killed at timeout, child gone, category `timeout`.
- A program printing to stdout directly (corrupting the protocol) → ignored lines, execution still bounded.
- A program returning a non-JSON value (function, BigInt, cycle) → `invalid_input`-free failure with category `internal`, no crash of the worker.
- Parent abort mid-call → pending nested call results discarded, child killed, category `canceled`.
- Tool name variants (`Kafka.publish`, `kafka.publish `, `mcp__platform__call_tool`) → denied, never resolved to a mutating tool.

### Task 2: Sandboxed runner and parent executor

**Files:**
- Create: `src/codeact/runner.mjs`, `src/codeact/execute.ts`
- Test: `test/codeact.test.ts` (unit, broker via injected launcher), `test/codeact-sandbox.integration.ts` (real sandbox; skipped with the probe's reason when unavailable)

**Interfaces:**
- Produces:
  - `type CodeActCall = (name: string, args: unknown, signal: AbortSignal) => Promise<{ ok: boolean; result?: unknown; error?: string }>`
  - `type CodeActTool = { name: string; summary: string; readOnly: boolean }`
  - `executeCode(req: { code: string; timeoutMs?: number }, deps: { tools: () => CodeActTool[]; call: CodeActCall; signal?: AbortSignal; launch?: Launcher; record?: (e: CallRecord) => void }): Promise<CodeActResult>`
  - `CodeActResult = { ok: boolean; value?: unknown; truncated?: boolean; error?: string; category?: Category; calls: Array<{ seq: number; tool: string; status: "ok"|"error"|"denied"|"timeout"; ms: number; input_sha256: string; output_sha256?: string; bytes: number }>; stats: { duration_ms: number; calls: number; result_bytes: number } }`
  - `codeActAvailability(): Promise<true | string>` (enabled flag + `probeIsolation().available`)
- Runner protocol (stdout lines): `{"t":"call","id":n,"name":..,"args":..}`, `{"t":"list"}`, `{"t":"done","value":..}`, `{"t":"fail","error":..}`; parent → stdin: `{"t":"start","code":..}`, `{"t":"result","id":n,"ok":..,"result"|"error":..}`, `{"t":"tools","tools":[..]}`.
- Program shape: body of an `async` function receiving `platform` (`callTool(name,args)`, `listTools()`); its return value is the result.

- [ ] Step 1: unit tests (injected `launch` = plain `node runner.mjs`, test-only): `multiple read-only calls are aggregated and only the returned value reaches the caller`; `a mutating or unknown tool is denied by the broker without calling it`; `name variants never resolve`; `oversized code is rejected before launch`; `infinite loop is killed at the timeout`; `abort cancels and kills the child`; `output above maxOutputBytes is truncated`; `call budget and result-byte budget stop further calls`; `non-serializable return fails cleanly`.
