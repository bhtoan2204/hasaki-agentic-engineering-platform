# P1-B LSP Semantic Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Semantic definition / references / document symbols / diagnostics / incoming calls for Go (gopls) and TS/JS, over an authorized checkout or the run's worktree, with typed statuses and provenance.

**Architecture:** `src/codeIntelligence/lsp/client.ts` speaks LSP (Content-Length JSON-RPC) to a child process; `tsServer.mjs` is a small LSP-shaped server over the TypeScript LanguageService API (no project plugins, file reads confined to the root); `sessions.ts` pools sessions per (language, root, workspace fingerprint); `navigate.ts` authorizes (`localScope`), validates paths (`readSource`), positions by symbol, rechecks freshness and bounds results. Workflow tool `navigate_code`, Chat tool `code.navigate`.

**Tech Stack:** gopls 0.24 (host), typescript 6 (repo dependency), bubblewrap sandbox when available, node:test.

**Spec:** `docs/superpowers/specs/2026-11-21-p1-codeact-lsp-taint-design.md` (section B).

## Global Constraints

- Disabled by default (`config.lsp.enabled = false`). Language servers run in the OS sandbox (root read-only, no network); without it they run only if `config.lsp.allowUnsandboxed` (default false), otherwise status `unavailable`.
- Go env: `GOPROXY=off GOFLAGS=-mod=readonly GOTOOLCHAIN=local CGO_ENABLED=0 GOWORK=off`, private GOCACHE; no other inherited secrets (`isolatedEnvironment`).
- Statuses: `ok | not_found | ambiguous | unsupported | unavailable | timeout | canceled | stale | unauthorized | invalid`.
- Defaults: maxSessions 4, idleMs 300000, requestTimeoutMs 15000, startupTimeoutMs 30000, maxResults 50.
- Locations outside the root (stdlib, lib.d.ts, module cache) are counted as `external`, never returned as paths.

## Review Focus

- A symbol name that matches several declarations → `ambiguous` with candidates, never a guessed pick.
- A file edited between two requests → new workspace fingerprint, session restarted, fresh answer.
- A file changed while a request is in flight → `stale`, no locations presented as current.
- Path with `..`, absolute, secret file or symlink component → `invalid`/`unauthorized` before any server sees it.
- gopls missing or crashing → `unavailable`, next request restarts a session.
